SEKOBRA es mi app personal para administrar las fechas en las que se cobran las suscripciones que pago y, a su vez, notificarme sobre dichos cobros. Por ahora, utiliza AsyncStorage de Expo para guardar los datos y, al ser una aplicación de uso personal, no requiere una implementación de base de datos.

Una vez compruebe su funcionamiento, completaré los módulos faltantes de la aplicación y realizaré una migración a Supabase, utilizando un stack que permita soportar una pequeña base de clientes. Además, contará con un sistema de inicio de sesión y almacenamiento de datos por usuario.
